# Study-with-Salwa

**Study with Salwa** est une application web de gestion des tâches destinée aux étudiants. Elle permet d'organiser les révisions, de planifier les échéances et de suivre l'avancement des tâches à travers une interface simple et interactive.

## Fonctionnalités

- Ajouter des tâches avec une date limite.
- Marquer les tâches comme terminées.
- Supprimer des tâches.
- Afficher le nombre total de tâches et le nombre de tâches terminées.
- Sauvegarder automatiquement les tâches dans le navigateur grâce à LocalStorage.
- Interface responsive, adaptée aux différentes tailles d'écran.

## Technologies et concepts utilisés

- **HTML5** : structure et organisation du contenu.
- **CSS3** : mise en forme et design responsive.
- **JavaScript** : logique de l'application et gestion des interactions.
- **DOM (Document Object Model)** : sélection, modification et manipulation dynamique des éléments HTML.
- **JavaScript Events** : gestion des événements utilisateur, comme les clics et les actions sur les tâches.
- **LocalStorage** : sauvegarde et récupération des tâches dans le navigateur.

## Installation et utilisation

1. Cloner ou télécharger le dépôt GitHub.
2. Ouvrir le fichier `index.html` dans un navigateur web.
3. Ajouter des tâches avec leurs dates limites.
4. Marquer les tâches comme terminées ou les supprimer selon les besoins.

## Objectif du projet

Ce projet a été réalisé dans le but de renforcer mes compétences en développement web Front-end et de mettre en pratique les concepts fondamentaux de JavaScript, notamment la manipulation du DOM, la gestion des événements et le stockage local des données.
